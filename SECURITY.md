# Security policy

Please do not report security issues in public GitHub issues.

Open a private security advisory in the GitHub repository, or contact the repository maintainers privately with:

- affected version or commit;
- reproduction steps;
- impact;
- suggested mitigation, if available.

Do not include live credentials or private project data in a report. IND is an early-stage project; users should review provider, command, policy, and memory-sync settings before using it on sensitive repositories.
